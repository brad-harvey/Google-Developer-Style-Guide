# Google Developer Documentation Style Guide — Condensed Reference

A condensed, reorganized reference to the [Google Developer Documentation Style Guide](https://developers.google.com/style), paraphrased from the original site and grouped to mirror its left-hand navigation. This is a working internal reference, not a verbatim copy — for exact original wording, follow the source link on any entry.

The original guide is published by Google and, except as otherwise noted on its pages, its content is licensed under the [Creative Commons Attribution 4.0 License](https://creativecommons.org/licenses/by/4.0/); code samples are licensed under the [Apache 2.0 License](https://www.apache.org/licenses/LICENSE-2.0). This reference attributes all guidance to Google's original style guide accordingly.

Per-page source extracts (one file per original page, mirroring the site's nav) live under [`pages/`](pages/). This index and the `guide/` section files are the condensed, cross-linked version of that same content.
